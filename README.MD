Weather App — приложение, разработанное с использованием фреймворка SwiftUI, предназначенное для предоставления пользователям актуальной информации о погоде.
Оно интегрируется с внешним API для получения данных о погоде, поддерживает кэширование данных и управление геолокацией.
Сервер для запроса данных предоставляет сервис https://www.weatherapi.com/ .

Основные функции:
1) Отображение текущей погоды: Показывает данные о температуре, состоянии погоды, скорости и направлении ветра, давлении и местном времени на основе текущего местоположения пользователя
2) Экран загрузки (Splash Screen): Отображает анимацию загрузки с кастомным дизайном во время получения данных о погоде
3) Кэширование данных: Сохраняет данные о погоде и изображения в локальном хранилище для оффлайн-доступа.

Архитектура и технологии:
1) Проект реализован на фреймворке SwiftUI
2) Для навигации между экранами используются Coordinator и Router 
3) Применяется MVVM архитектура
4) Реализованы Dependency Injection
5) Асинхронное программирование через async/await
6) Сетевые запросы выполняются через NetworkService()
7) Кеширование данных через CacheManager()
8) Геолокация через LocationManager()
9) Вложенность типов для упрощения вариации имен Namespacing.

Структура проекта:
1) AppCoordinator: Главный координатор, управляющий основным потоком навигации приложения
2) HomeCoordinator: Координатор домашнего экрана, определяющий начальный экран в зависимости от состояния (Splash, Current, Forecast, Lost Connection)
3) HomeFactory: Фабрика для создания представлений и их ViewModel'ей для различных экранов
4) Router: Класс для управления навигацией с использованием NavigationStack.

State Management:
1) SplashState: Управляет состоянием экрана загрузки
2) ConnectState: Отслеживает состояние подключения к интернету
3) WeatherState: Хранит данные о текущей погоде.

API интеграция:
1) APIService: Отвечает за выполнение запросов к API погоды (текущая погода, прогноз, изображения)
2) Endpoint: Определяет параметры для сетевых запросов (схема, хост, путь, метод, query-параметры).

Менеджеры:
1) LocationManager: Управляет запросами геолокации
2) CacheManager: Отвечает за кэширование данных
3) NetworkService: Выполняет сетевые запросы с учетом кэширования
4) DecoderService: Декодирует JSON-ответы от API.

Ключевые компоненты пользовательского интерфейса:
1) SplashScreen: Отображает название приложения, анимацию загрузки и градиентный фон
2) CurrentWeatherScreen: Показывает текущие погодные данные (местоположение, температура, состояние погоды, ветер, давление)
3) ForecastScreen: Планируется для отображения прогноза погоды на несколько дней
4) LostConnectionScreen: Информирует пользователя о проблемах с соединением
5) Кастомные модификаторы и цвета: Реализованы через BackgroundModifier и кастомные цветовые схемы для каждого экрана.

Константы и настройки: 
1) API: Используется внешний сервис погоды (WeatherAPI) с заданным ключом и хостом (api.weatherapi.com)
2) Шрифты: Кастомный шрифт ChironGoRoundTC в вариантах Bold, Medium, Regular
3) Цвета: Определены через HEX-коды для единообразного дизайна (например, SplashScreenBackgroundColor, CurrentTextColor)
4) Кэширование: Используются ключи responseWeatherKey и responseImageWeatherKey для сохранения данных и изображений.


Особенности и преимущества:
1) Модульность: Архитектура позволяет легко добавлять новые экраны и функции
2) Гибкость: Использование протоколов (RoutingLogic, HomeFactorable, APIServicable, и др.) упрощает замену реализаций
3) Кэширование: Улучшает производительность и обеспечивает оффлайн-доступ к данным.
